# Aragocor Minerals static site package

This repository contains a deployable static reconstruction of the public page at:

`https://aragocor-minerals.jlerner1965.chatgpt.site/`

## Files

- `index.html` — complete one-page website
- `styles.css` — responsive styling
- `script.js` — mobile menu, sticky header and form interaction
- `*.jpg` — locally packaged image assets used by the page
- `source-url.txt` — original public URL

## Deploy

This site can be deployed with GitHub Pages, Netlify, Hostinger, Cloudflare Pages, or any conventional static host. No build command is required.

## Important

The inquiry form is front-end only. Connect it to a form endpoint, CRM, email automation, or serverless function before production use.
